## Failures encountered and corrected

- Initial shell sandbox made installed runtimes appear unavailable. Authorized execution confirmed Java/Maven/Node/npm/Docker. The macOS Java locator in the Maven launcher avoids the inherited incorrect JAVA_HOME.
- An initial frontend JSX option-tag error was fixed.
- Playwright and axe initially resolved different Playwright-core versions. Both now use pinned Playwright 1.64.1.
- The first browser run caught checkbox state reverting during asynchronous URL navigation. Immediate local filter state and retained result data fixed it.
- Error assertions were scoped to main content to avoid Next.js's route announcer; navigation assertions now wait for the requested sort URL before recording it. No acceptance assertion was removed.
- The HTTP schema test required an explicit JSON import attribute under Node ESM; corrected and rerun successfully.
- Initial npm development-tool advisories were removed by updating Redocly/Vitest; an added Ajv validator was updated to 8.20.0. Final audit reports zero npm advisories.
- Testcontainers modules were aligned with the Spring Boot BOM (2.0.5); deprecated Jackson test calls were replaced. Final editor diagnostics are clear.
- Final review found impossible same-day return times in the synthetic schedules. The domain now rejects return-before-arrival itineraries; the provider allows an hour after arrival and omits returns that would depart on a different requested date. Departure-time expiry also prevents repricing a departed flight. Regression tests pass. A same-day return search now correctly yields six feasible sample options, while later-date returns retain eight.
